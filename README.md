# 🏪 দামের খাতা (Damer Khata)
> **গ্রামের ছোট দোকানের জন্য অফলাইন-সক্ষম, স্ব-আপডেটকারী Android অ্যাপ্লিকেশন**

নরসিংদীর বেলাবো থানার ছোট দোকানের জন্য বিশেষভাবে তৈরি আধুনিক হিসাবের খাতা ও দামের তালিকা। 

---

## ✨ প্রধান বৈশিষ্ট্যসমূহ

1. **শতভাগ অফলাইন**: ইন্টারনেট বা ডেটা প্যাক ছাড়াই দোকানে সব কাজ (মাল খোঁজা, বিক্রি, বাকি, খরচ) নির্বিঘ্নে চলে। ফন্ট (কালপুরুষ) অ্যাপের ভেতরেই সম্পূর্ণ এমবেড করা।
2. **গোপনীয়তা নিশ্চিত**: হোম পেজে কখনোই কেনা দাম বা লাভ দেখায় না। কাস্টমার সামনে দাঁড়ালেও শুধু বিক্রির দাম দেখবে। কেনা দাম ও হিসাব PIN দিয়ে সুরক্ষিত।
3. **স্বয়ংক্রিয় রিলিজ ও লাইভ আপডেট (OTA)**: 
   - কোডে বা `app.html`-এ কোনো পরিবর্তন করে GitHub-এ পুশ করলেই GitHub Actions স্বয়ংক্রিয়ভাবে নতুন **Release** তৈরি করে।
   - ইনস্টল করা ফোনগুলোতে অ্যাপ খোলার সাথে সাথে ব্যাকগ্রাউন্ডে GitHub Raw URL থেকে আপডেট ডাউনলোড হয়ে যায় এবং স্ক্রিনে বার্তা আসে: `"app-এর নতুন version এসেছে" + "এখনই চালু করুন"` বাটন। APK বারবার রি-ইনস্টল করতে হয় না!
4. **ব্যাচে কেনাকাটা ও আনুপাতিক খরচ বণ্টন**: চকবাজার, বাবুরহাট ইত্যাদি বাজার থেকে একবারে অনেক মাল কিনে গাড়ি ভাড়া ও ঘাট খরচ দিলে প্রতি মালের কেনা দামের অনুপাতে খরচ স্বয়ংক্রিয়ভাবে ভাগ হয়ে যায়।
5. **২-ফোন সিঙ্ক (Google Apps Script)**: দোকানে দুটি ফোন (Tecno Spark 40 Pro এবং Redmi Note 10 Pro) থাকলে দুটো থেকেই বিক্রি লেখা যায়। ইন্টারনেট পেলেই কোনো বিক্রি না হারিয়ে গুগল ড্রাইভে সব হিসাব নিখুঁতভাবে মিলে যায়।
6. **ক্যাশ মেলানো ও বাকির খাতা**: ড্রয়ারের ক্যাশ মেলানো, WhatsApp তাগাদা মেসেজ, এবং পাইকারের ডিরেক্টরি।

## 🛠️ রিপোজিটরি ফাইল পরিচিতি

- **`app.html`**: সম্পূর্ণ একক ফাইল ওয়েব অ্যাপ্লিকেশন (HTML + CSS + JS + কালপুরুষ ফন্ট ইনলাইন্ড)।
- **`release/damer-khata.apk`**: ডিজিটাল সাইন করা ইনস্টলার ফাইল।
- **`release/damer-khata.jks`**: রিলিজ কি-স্টোর ফাইল (ভবিষ্যতে সাইন করার জন্য)।
- **`Code.gs`**: গুগল ড্রাইভ সিঙ্ক ও ২-ফোন মেলানোর জন্য Google Apps Script ব্যাকএন্ড।
- **`app/`**: Android Studio সোর্স কোড (Java, Native WebView Shell, Biometric, MediaStore Backup)।
- **`.github/workflows/release.yml`**: গিটহাবে পুশ করলেই অটোমেটিক রিলিজ তৈরি করার CI/CD পাইপলাইন।
- **`build_apk.py`**: কমান্ড-লাইন APK বিল্ড ও সাইন স্ক্রিপ্ট।
- **`test_suite.py`**: ১০টি গ্রহণযোগ্যতা পরীক্ষার স্বয়ংক্রিয় টেস্ট স্ক্রিপ্ট।
- **`README_SETUP_BN.md`**: বাংলায় পূর্ণাঙ্গ সেটআপ ও ব্যবহারের গাইড।
